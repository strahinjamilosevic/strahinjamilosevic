## Why

The Logistics API let Adyen's supply chain automate delivery workflows and replace an aging messaging system under a fixed deadline. It had to stay inaccessible to the public.

## What

Partners needed to find and use the API without it appearing in the official API reference tooling. The API was still in development when documentation work began.

## How

I wrote the API reference directly from Stoplight mockups. I designed an information architecture that made the API discoverable only to intended users, through navigation and structure instead of tooling.

I found inconsistencies across endpoints and led the effort to simplify the request and response schemas.

## Result

Partners migrated off the legacy system before the planned deadline. The schema work influenced API design decisions that made integrations easier and more reliable.
