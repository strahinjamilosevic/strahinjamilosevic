I have over a decade of experience in technical roles, with the last eight specializing in technical writing and documentation engineering across fintech, payments, crypto, and industrial hardware. For the full stories behind these roles, see [Projects](/projects).

## Senior Technical Writer, Bitvavo

November 2024 – Present | Amsterdam, Netherlands (hybrid) | [docs.bitvavo.com](https://docs.bitvavo.com)

Sole technical writer for Bitvavo's Exchange domain: API documentation, developer portal, and docs-as-code platform for REST, WebSocket, and FIX APIs.

- Replaced the Redocly site with a Docusaurus developer portal within 4 months of joining, as sole technical writer and docs engineer for the Exchange domain (5 teams, 50+ developers). Reached 73,000+ new users in the first year and a peak of 10,000 monthly active users.
- Documented the full exchange API portfolio: 8 APIs spanning trading, market data, RFQ, and institutional subaccount and leveraged-account management. Standardized them as OpenAPI (REST), AsyncAPI (WebSocket), and XML (FIX).
- Restructured 12,000+ lines of API definitions into a modular single-source repository. This enabled schema-generated examples and AI-assisted workflows, and removed the tech debt blocking framework upgrades.
- Set up the Kubernetes deployment and CI/CD pipeline for the docs platform, working with platform and DevEx teams, and took over pipeline ownership to enable same-day releases.
- Redesigned the information architecture: use-case navigation, Algolia search indexing parameter-level content, reusable shared topics, and date-based release notes with RSS and breaking-change previews.
- Secured Bitvavo's verified Postman publisher status and launched a public REST and WebSocket workspace with an authentication environment and signature-generation scripts.
- Launched an API governance initiative with staff engineers covering naming, authentication, rate limits, error handling, and backward-compatible change management.
- Automated per-API spec downloads, PR preview environments and UAT staging for unreleased APIs, all generated from the same source as the published docs.
- Launched an in-docs feedback widget and GA4 analytics, and turned user-reported issues into FAQs and actionable error-handling guidance.
- Rebuilt the docs homepage with custom Docusaurus components (clickable tiles, a mini table of contents, skip-to-content) and split the top navigation into Docs and API sections, with APIs grouped by Trading, Market Data, and Institutional.
- Set up ticket templates, contribution workflows, and review processes across API teams.
- Documented WebSocket channels in adapted OpenAPI in 2025, while AsyncAPI was not yet mature enough. Migrated them to AsyncAPI once it could describe all authentication, errors, and request, response, and event structures, which simplified the tooling, and built a cleaner component for the docusaurus-openapi-docs plugin.

Case studies: [API docs platform](/projects/bitvavo-api-docs-platform) and [docs strategy](/projects/bitvavo-docs-strategy).
